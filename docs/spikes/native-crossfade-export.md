# Public QuickJS crossfade export

This probe closes the public authoring-to-packaged-gameplay link for the native
crossfade SDK. It does not add a player mode, renderer, mutation route or runtime
compiler. It combines the reviewed crossfade core/SDK and canonical CPU consumer.

Run `python3 tools/probes/native-crossfade-export.py NEW_OUTPUT --binary HEADLESS`
with a freshly built matching headless binary. The helper uses the existing
one-joint/two-clip numerical glTF unchanged. Public init/import and one command
transaction author two instances, a stationary camera and a strict TypeScript
behavior. Undo/Redo, save and reopening the editor-default journal verify the
ordinary project/source paths. The instances begin with running and paused
outgoing clocks; no font, OS discovery, provider or account is involved.

Each accepted callback copies all four destination and six transition fields into
one bounded log per instance. Existing transform lanes expose selected values to
the ordinary numerical observation plan. An independent table checks 62 complete
rows across pause/resume, destination speed/loop changes, captured paused sources,
completion, rest, zero-duration selection and Seek/Select cancellation. Reads
after queued controls must remain identical during the callback. One hundred
ticks emit 200 entries, below the existing 1,024-entry/256-KiB history limits.

The existing exporter makes a fresh shipping-profile `project,render-input`
player, checks the actual compiler flags and bytecode-only symbols/dependencies,
packages only cooked assets and deletes its private build storage. The probe then
deletes only its own authoring/source/cache fixture. Three fresh sanitized-env
processes use the existing `--package`, observation and checkpoint options. Full
reports, committed logs, PCM and checkpoint bytes must agree. Separate runs split
at active and paused transitions, verify world-save v5 inside the framed session
checkpoint, and compare fresh continuation with the uninterrupted result.
Corrupted checkpoints and wrong numerical observations must withhold PCM/save
outputs. Earlier failed runs, if any, remain evidence rather than validated runs.

The available boundary is accepted SDK logs, requested native numerical values
and the final CPU render-input report. It does not expose deformed vertices and
does not submit GPU work. This is QuickJS compiled project bytecode. Public Wasm
project selection/export remains an implementation gap; actual Wasmtime/static
wasm2c guest conformance is recorded separately, and complete static module-state
checkpointing remains unsupported. PCM comparison checks this fixture's silent
output and sample clock, not additional audible-content correctness.

The frozen local run (`001`) passed: three complete 100-tick fresh players, two fresh
checkpoint continuation pairs and two intended refusals. Each complete run
produced the same 200 accepted entries (15,627 message bytes, zero dropped),
640,000 silent PCM bytes and final checkpoint bytes. Both mid-run checkpoints
contain active transitions and use world-save v5; the completed final state keeps
the older v4 encoding. The exported 8,673,056-byte arm64 player was freshly built
with the existing shipping profile. These sizes describe this fixture, not a
device memory or performance gate.

[The frozen receipt](evidence/native-crossfade-export.json) records the minimum
reviewed union, unchanged rig fingerprints, matching headless build, actual
shipping compiler/flags, package and process hashes. The private source/cache
directory and exporter build target are absent; the exported package and process
receipts remain available for review. That run retained the exporter's external
`package/symbols/behavior.js.map`, including the original TypeScript in
`sourcesContent`. It proves removal of authoring/source/cache/build inputs and
cooked-only runtime execution, without claiming every external debug copy was
removed. The exporter also ran its ordinary
one-tick startup check after build deletion, before authoring deletion; that check
is separate from the three authoring-source-deleted 100-tick runs.

The current probe strengthens subsequent runs by hashing and deleting only its
newly-created external JavaScript source-map artifacts before launching players.
The normal exporter and original `001` artifacts are unchanged. This strengthened
probe has passed a focused artifact-removal check; a complete fresh recook/export
with it has not yet run and remains part of publisher integration validation.

No window, graphics, appearance, device/performance, full animation graph/state
machine/IK/root motion or phase-gate acceptance is claimed.
