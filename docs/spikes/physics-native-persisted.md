# Checked native persisted rigid subset

This is a default-off native byte-admission candidate under `incant-checked-restore`.
It does not open existing runtime, session or player file-save APIs. Independent
successor source review and scoped deterministic/fast CPU qualification pass. Final producer evidence review and outer save integration
remain separate. No GPU work is involved.

`NativeFrame::persisted_bytes(&mut Budget, &mut WorkBudget)` independently validates
the stricter editable-data domain, then charges and copies the exact retained
native envelope. Decode scratch and output consume the same cumulative payload
budget. `CheckpointOwner::from_persisted(bytes, payload, work, allocations)` checks
the actual linked dimension/build, decodes and joins all inert sections, validates
derived values and this domain, then constructs a complete unpublished candidate
under one cumulative allocation permit. It uses the receiving library's default
query dispatcher and execution pool. No serialized pointer or caller identity
selects those owners.

Imported readiness is private `ImportedValidated`, never a historical-completion
claim. It permits immediate opaque recapture and re-export, but cannot issue
`CompletedStep`. Opaque reconstruction preserves that origin. An actual positive
step can issue completion, while the imported lineage keeps its pre-step counter
and unsupported-family/configuration fences. Mutable access invalidates readiness before borrowing;
ordinary native Rust callers remain responsible for using checked structural
plans instead of bypassing them through raw native operations.

The envelope remains `ICNATIV1` plus the unchanged joined `ICWORLD1` sections.
Lengths and budgets precede allocation, identity is independently derived, and
saved state is not normalized or regenerated. Compatibility fingerprints do not
authenticate history. Arbitrary edited warm values are not proof that a prior
collision or simulation actually occurred.

## Additional admitted domain

- Closed primitive shapes and the existing flat spatial-compound/planar-tile
  domain, with exact child order/poses/acceleration and material/body joins.
  Current solver clusters are refused because mixed-child point provenance is
  not yet established. Existing custom/nested/soft/joint refusals remain.
- CCD configuration admits zero or one pass, including the actual default one.
  More than one pass refuses before construction and before each imported step:
  shortened TOI solver intervals are not admitted. Soft prediction and the fast
  rotation opt-out refuse. Enabled/active flags, all three verdict values, and
  all three fixed-cache states retain exact bits. Existing inert checks establish
  complete fixed-target membership/order/generations; derived checks establish
  exact bounds using the historical prediction. No cache is regenerated.
- Ordinary post-solve CCD clamping is supported for the closed shape set. Every
  fast dynamic body can activate it, even with ccd_enabled=false. Directed child
  pairs are precharged for two complete bounded TOIs (including overlap retries)
  and endpoint checks. Units are logical iteration visits, not CPU instructions,
  memory, or latency. Scalar bounds include independent collider/world and
  parent/child offsets, local COM, predicted motion, radii and effective `5 * slop`.
  Degree-six setup bounds cover squared triple-cross GJK arithmetic. They are
  not a proof against every tiny barycentric divisor or of query precision;
  native fraction comparisons bound published clamps and native numerical
  failure isolation remains necessary. Positive normal quarter-slop avoids the
  pinned TOI target/tolerance assertion; native angular capping is retained.
- Query-visible enabled leaf bounds must contain current geometry plus the
  native skin/prediction margin. All retained ancestors must already contain
  their children, even along pending paths. Bounds/flags/queues are never rebuilt.
  BVH flags `01`/`11` denote changed/pending, not enablement; exact deferred flag
  propagation remains governed by the named pending-tree witness.
- Current active material coefficients and effective dominance must match their
  native joined values. Packed primitive contact features must be emitted by the
  actual closed shape; cuboid clipping codes are checked through the pinned
  support-feature routine rather than mistaken for dense face indices. Unknown
  GJK features remain admitted.
- Recycle caches retain their historical poses but must have exact current-shape
  extent and no excessive current drift allowance. Fast detector records must
  use their documented canonical key order; deterministic records retain order.
- Saved consumed arithmetic receives additional finite scalar/vector bounds,
  unilateral warm-impulse checks, force-integrated velocity bounds, and 3D gyro
  momentum checks. The f64 absolute-sum model retains 64-fold headroom for the
  fixed-width setup expressions; it is a stricter documented scalar domain, not
  clamping or proof of finite output for every future solver iteration/edit.
  Native numerical failure isolation still applies after real simulation.
- Before an imported step, persistent island counts plus queued unlink rows,
  body-slot count and (2+max(1,max_ccd_substeps)) times the complete collider-pair
  count must fit u32. Two modified endpoints can each unlink/relink, then each
  possible collision-detect pass can unlink again. The current domain admits
  at most one pass by configuration, not by body flags. Merges preserve the total; splits can reset it. The same
  bound is checked before construction with an empty validated journal. Sparse
  VecMap iteration is charged by retained capacity, not occupied count. This is
  logical work/counter accounting, not CPU-time or future heap-allocation proof.
