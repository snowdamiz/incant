## Trusted host boundary

```sh
python3 tools/probes/native-player-capture-packages.py jobs.json NEW_OUTPUT \
  --seconds 3600
```

The data-only jobs file admits one to four records containing `name`, absolute
`project`, and optional canonical `scene`/`camera` ULIDs. Jobs cannot supply
commands, feature flags, tools or executable shaders. Static-module scenes
explicitly refuse in this slice. No window or GPU route is launched by this
helper, despite the packages being window/capture capable.

It uses the existing `shipping_session.FreshSession`, with absent ephemeral
storage, frozen source/compiler/target/profile inputs and actual Cargo commands
joined to exact target artifact hashes. Only proven identical units from that
same session may be reused. Previously packaged, hashed players must retire
before the next player compilation; an unproven cached player, changed shared
artifact or unexpected rebuild refuses. There is no persistent dependency cache.

Every authoring tree is copied without links or special files and checked
before and after compilation: at most 4,096 files/256 MiB per tree and 512 MiB
combined. The qualified inputs were 404 files. Packages preserve their own
project, scene, compiler output, code-generation, feature graph and executable
identities. All four packages precede the deletion barrier. Only then do the
four one-tick startups run, with `gpu_submitted:false`; `frames:800` means PCM
sample frames, not 800 gameplay ticks. Complete batch publication is last.
Failures retain earlier independent outcomes and partial evidence.
