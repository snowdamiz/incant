# Trusted mobile bytecode on main169

The exact eleven reviewed compiler, build, fixture and admission inputs are
integrated on actual main169. The only source integration conflicts were additive
STATUS sections. Dependency resolutions and the reusable player implementation
remain unchanged. The new route accepts fresh trusted source for the pinned
macOS ARM to iOS ARM device/simulator pairing; it does not retarget arbitrary
executable caches or enable authored-project cross-export.

All sixteen commands passed against frozen source `c6bb65f0`. Script tests pass
181 cases in eight groups, selected cooker tests pass eight cases in three groups,
and the mobile player tests pass thirteen cases in five groups, with no failures
or ignored tests. Scoped all-target Clippy, dependency checks, formatting,
conventions, diff and caller-helper tests pass.

New immutable `ci` archives were built separately for macOS, iOS simulator and
iOS device, all with `mobile-ffi` and the same trusted numeric fixture. C and Swift
callers execute 32 controls / 39 commands on macOS and 32 controls / 44 commands
on the iOS simulator. The device archive passes seven compilation/link commands;
no physical-device execution occurred. The disposable simulator was shut down and
deleted by the caller harness.

Complete game reports and PCM match exactly across C/Swift and macOS/simulator
for held input, repeat, release and deliberately failed observation cases. The
fixture checks IEEE values, BigInts, captured state, Unicode, native motion,
clock/input and post-write failure behavior. Malformed input and no-clobber
outcomes retain their precise expected statuses. Independently generated bytecode
and hardening arrays match their metadata hashes and each other across all three
destinations; target identities remain distinct.

The [manifest](evidence/mobile-bytecode-main169.json) binds 1,884 frozen inputs,
eleven exact producer comparisons and 379 retained artifacts, including complete
commands, reports, requests, PCM and source/build identities. Large archives and
caller executables remain hash-bound outside the repository. Original producer
proof and its independent review remain separately preserved. The private target
was cloned from an idle cache, assigned to this checkout, and only cloned local
package outputs were cleaned before validation.

[Final independent integrated audit](evidence/mobile-bytecode-main169/final-review.json)
is accepted; exact-head fast CI remains required before merge. This CPU
fixture does not claim shipping-profile, phone performance, rendering, signing,
Android admission or authored-project iOS export. A separate ordinary desktop
export detected the player library/bin audit ambiguity after main169; that failed
export is retained by its owner and is not part of this fixture's success claim.
