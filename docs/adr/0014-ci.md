# ADR 0014: GitHub Actions and target-specific runnable probes

Date: 2026-10-08. Status: proposed for director review.

## Decision

Use GitHub Actions for repeatable builds and nightly target artifacts. Pin action revisions, Rust, Node dependencies and Cargo resolutions. Dedicated live-eval secrets are only exposed to a manually invoked protected evaluation job. CI never invokes coding agents.

## Evidence and implementation boundary

Desktop, WASM, iOS and Android hosts share incant_platform_smoke. Local macOS, browser and iOS simulator execution is measured. The private remote is snowdamiz/incant. All six PR-triggered target builds have passed, with desktop, browser and iOS simulator execution. Android emulator execution is now implemented and awaiting its first CI run. Real-backend synthetic credential persistence across changed executables passes on all three desktop hosts. Nightly artifact history and signing remain pending.

## Consequences and revisit trigger

Development/debug artifacts are not signed distribution releases. Director-managed Apple/Windows certificates, hosted or self-hosted runner provisioning, Android SDK licenses and physical-device access must precede release gating. Self-hosted runners must never run untrusted fork code with signing/eval credentials.
