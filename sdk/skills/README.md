# Bundled agent playbooks

These eighteen Markdown playbooks are compiled into incant_agent and exposed by
skill_list and skill_read. They need no network, engine account or runtime file
access. The shared contract is returned with the selected playbook. Projects
cannot override this catalog by writing files or memory; playbooks do not grant
permissions, bypass approvals or execute helpers. No TypeScript helpers are
bundled in this version.

The playbooks guide composition using actual available engine capabilities and
require explicit reporting where a host or runtime lacks one. Their existence
does not establish that all requested mechanics, provider evaluations or phase
exit gates have passed. Changes to a playbook ship with the matched engine build.
